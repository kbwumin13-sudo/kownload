# kownload

常駐選單列的 macOS 下載面板，支援 HTTP、BT／磁力、ED2K、網頁媒體及網盤檔案。

目前發行 macOS 12+、Apple Silicon 版本。其他平台原始碼保留，尚未發行獨立版本。媒體下載需要另行安裝 yt-dlp、FFmpeg 與 Node；實際網盤驗證範圍請參閱主文件。
