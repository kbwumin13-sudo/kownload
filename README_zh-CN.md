# kownload

常驻菜单栏的 macOS 下载面板，支持 HTTP、BT/磁力、ED2K、网页媒体和网盘文件。

本项目当前发行范围是 macOS 12+、Apple Silicon。其他平台源码保留，尚未作为独立版本发行。媒体需要另行安装 yt-dlp、FFmpeg 和 Node；网盘真实验收范围以主文档为准。
