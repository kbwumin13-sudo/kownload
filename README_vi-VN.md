# kownload

Bảng tải xuống trên thanh menu macOS, hỗ trợ HTTP, BT/Magnet, ED2K, nội dung đa phương tiện trên web và tệp từ dịch vụ lưu trữ đám mây.

Bản phát hành hiện tại dành cho macOS 12 trở lên, Apple Silicon. Mã nguồn nền tảng khác được giữ lại nhưng chưa có bản độc lập. Tính năng đa phương tiện cần cài riêng yt-dlp, FFmpeg và Node. Phạm vi kiểm thử dịch vụ đám mây được ghi trong tài liệu chính.
