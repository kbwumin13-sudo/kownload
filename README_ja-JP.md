# kownload

macOS のメニューバーに常駐するダウンロードパネルです。HTTP、BT／Magnet、ED2K、Web メディア、クラウドストレージに対応します。

現在の配布対象は macOS 12 以降の Apple Silicon です。ほかのプラットフォームのソースは残っていますが、独立版として配布していません。メディア機能には yt-dlp、FFmpeg、Node の別途インストールが必要です。クラウドサービスの実機検証範囲はメイン文書をご確認ください。

- [インストール](README.md#安装)
- [リリース](https://github.com/kbwumin13-sudo/kownload/releases)
- [不具合報告](https://github.com/kbwumin13-sudo/kownload/issues)
- [ライセンスと出典](THIRD_PARTY_NOTICES.md)

更新は通知と Release ページへのリンクのみです。自動ダウンロードやインストールは行いません。拡張機能の設定、更新、Git URL による手動インストールを利用できます。オンラインマーケットとインストール統計送信は無効です。

[旧プロジェクトの原文](docs/upstream/README_ja-JP.md)は出典記録として保存しています。
