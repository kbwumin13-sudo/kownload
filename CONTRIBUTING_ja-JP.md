# kownload への貢献

現在の配布対象は macOS 12+ / Apple Silicon です。互換 ID、タスク、拡張設定、第三者の権利表示を維持してください。

`ui/flutter` で `flutter test` と `flutter analyze --no-fatal-infos --no-fatal-warnings`、関連する Go テストを実行します。[ビルド手順](docs/RELEASING.md)。
